# NexBoard - Trello-Style Project Management Board

NexBoard is a clean, modern, and highly responsive project management board designed for both desktops and mobile devices. It mirrors a Trello-like flow with Backlog, To Do, In Progress, Review, and Done columns, complete with visual activity logs, performance statistics dashboard, and a premium glassmorphic UI.

## Structure
- `index.html`: Core structure of the page, responsive across resolutions.
- `css/styles.css`: Pure custom CSS layout, visual variables, fonts, and responsive media queries.
- `js/app.js`: Lightweight JavaScript logic for switching columns on mobile view and interactive modal display.

## Installation & Setup
1. Clone or download this project workspace.
2. Open `index.html` directly in any web browser, or run a local development server:
   ```bash
   npx serve .
   ```
3. Resize the browser to experience the seamless transition between the Desktop dashboard and the Phone interface.
